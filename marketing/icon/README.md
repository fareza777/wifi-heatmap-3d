# WiFi Heatmap 3D icon

`icon-master.png` is the original image generated with the built-in Imagegen tool. `play-icon-512.png` is the 512 × 512 opaque PNG export for Google Play. The Android app uses a matching bitmap in `drawable-nodpi/ic_launcher_art.png`; the monochrome themed icon retains the existing native Wi-Fi vector.

Prompt: Premium Google Play icon, full-bleed opaque navy square, no text/border/rounded outer corners. Recognizable luminous near-white Wi-Fi glyph over a compact isometric heatmap floor transitioning cyan/emerald through yellow to coral. Restrained sculptural depth and precise edges, legible at 48 px, central safe-area composition. No phones, screenshots, ratings or badges.

The master was generated by OpenAI Imagegen. Export only changes pixel dimensions/encoding, not visual content. Declare AI assistance if the current Play Console asset form asks.
